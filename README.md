# B2B 아웃바운드 리드 발굴 실습

아웃바운드 CRM 제품을 만들기 전, 직접 리드 발굴을 실습해 **페인을 체득하고 제품 가설을 검증**하는 프로젝트.

---

## 배경

만들고 있는 제품: **세일즈 인력 없는 초기 B2B 팀이 검증된 잠재 고객을 찾고, 한 곳 한 곳과의 관계를 관리해 첫 유료 고객을 만드는 아웃바운드 CRM**

리드 발굴 실습을 통해 두 가지를 동시에 한다:
1. 리드 발굴의 진짜 페인 직접 체득
2. 본인 제품 가설 검증 (어디서 막히는지가 곧 제품 스펙 근거)

---

## 페르소나 구조

30개 페르소나를 두 갈래로 정의. 자세한 내용은 [personas.md](personas.md) 참고.

| 구분 | 수 | 특징 | 핵심 페인 |
|---|---|---|---|
| A. 개발자 출신 대표 | 15 | 수평적 기술 제품 빌더 | 고객 식별이 어려움 |
| B. 도메인 출신 대표 | 15 | Vertical SaaS 빌더 | 의사결정자 연락처 확보가 어려움 |

**포함 조건**: 설립 6개월~2년차 · 팀 2~7명 · 시드/AC 졸업 · B2B

---

## 폴더 구조

```
/lead
  CONTEXT.md          프로젝트 전체 맥락
  personas.md         30개 페르소나 상세 정의
  METHOD.md           발굴 방법론 및 CSV 스키마
  viewer.html         leads / data_points / contacts CSV 동시 열람 뷰어
  leads/
    A01_kyc_aml/
    A02_d2c_inventory/
    ...
    B15_public_bid_domain/
      leads.csv        회사당 1행 — 상태 트래킹
      data_points.csv  (회사 × 필드 × 소스)당 1행 — 팩트 데이터
      contacts.csv     (회사 × 사람)당 1행 — 연락처
      source_log.md    소스/키워드별 탐색 기록
      agent_log.md     Claude Code 세션 행동 기록
```
